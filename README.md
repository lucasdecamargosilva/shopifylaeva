# Provador Virtual Laeva — Shopify

Widget do Provou Levou para a loja `loja.laeva.com.br`.

- Carrega apenas em páginas reais de produto da Shopify.
- Mantém o WhatsApp obrigatório antes do envio da foto.
- Reconhece leggings, calças, shorts e ciclistas como peças inferiores.
- Reconhece tops, croppeds e regatas como peças superiores.

URL pública do script:

```text
https://cdn.jsdelivr.net/gh/lucasdecamargosilva/shopifylaeva@main/provador-laeva.js
```
